## ฝั่งทีม (technical changelog)

### กิจกรรมกำหนดชั้นปีที่อนุญาตได้หลายค่า (commit `6e85c91`)

- **DB/migration:** เพิ่มคอลัมน์ `events.allowed_years` แบบ nullable jsonb ผ่าน `drizzle/0037_event_allowed_years.sql` และเพิ่มคำสั่ง `ADD COLUMN IF NOT EXISTS` ใน `src/db/migrate.ts` โดยยังเก็บ `first_year_only` ไว้เพื่อรองรับข้อมูลและ client รุ่นเดิม ต้องรัน `npm run db:migrate:container` บน production ก่อน deploy โค้ดที่อ่านคอลัมน์ใหม่
- **สิทธิ์สมัครกิจกรรม:** เพิ่ม helper กลางใน `src/lib/event-access.ts` สำหรับแปลงค่าระหว่าง `allowedYears` กับ `firstYearOnly` และตรวจว่าชั้นปีของนักศึกษาตรงกับรายการที่กิจกรรมอนุญาตหรือไม่ พร้อม unit test ครอบคลุมค่าปกติ ข้อมูล legacy และค่าที่ไม่ถูกต้อง
- **Admin/API/UI:** schema ของ route สร้างและแก้ไขกิจกรรมรับชั้นปี 1 ถึง 4 ได้หลายค่า หน้าแอดมินแสดง checkbox และ badge ตามชั้นปีที่เลือก ส่วน pending changes ของประธานยังเปรียบเทียบกับข้อมูลปัจจุบันได้โดยไม่สร้าง diff ซ้ำ
- **i18n:** เพิ่มข้อความสำหรับตัวเลือกชั้นปีในภาษา EN, TH, MM และ CN

### เอกสารออกแบบและ workflow การส่งงาน (PR #226)

- **Name schema:** เพิ่ม handoff ที่กำหนดให้ `users.name` ยังเป็นชื่อแสดงผลหลัก ข้อมูลชื่อจริงและนามสกุลจะบันทึกเมื่อมนุษย์ยืนยันเท่านั้น และไม่ส่งค่าที่ระบบเดาไปยัง export หรือเอกสารทางการ
- **Shop marketplace:** เพิ่มแบบระบบร้านค้าหลายผู้ขายที่ครอบคลุม seller approval, product approval, การแยก order ตามผู้ขาย, payment QR รายผู้ขาย, access scope และ audit trail
- **Workflow:** เพิ่ม skill สำหรับขั้นตอน branch, PR, merge, semver tag, GitHub Release และ changelog ของ repository นี้
- **Validation:** `npm run build -- --webpack` ผ่านครบ ส่วน `npm run lint` ยังพบ error เดิมใน `src/app/api/battle/rooms/battle-flow.test.ts` เรื่อง `no-explicit-any` ซึ่งไม่อยู่ในไฟล์ที่เปลี่ยนรอบนี้
