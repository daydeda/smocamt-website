# ActiveCAMT v2.20.1 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 9 ต.ค. 69

สรุปสำหรับวันที่ 9 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **แถบเมนูด้านบนดูสะอาดขึ้น** มุมซ้ายของแถบเมนูเหลือแค่ชื่อ ActiveCAMT ส่วนโลโก้ SMO CAMT ย้ายลงไปอยู่ท้ายหน้าแทน
- **มีส่วนท้ายหน้า (footer) แล้ว** ทุกหน้าในแดชบอร์ดและหน้าเกม P2P จะมีโลโก้ SMO CAMT ข้อความเครดิตว่า ActiveCAMT พัฒนาและดูแลโดยสโมสรนักศึกษาวิทยาลัยศิลปะ สื่อ และเทคโนโลยี มหาวิทยาลัยเชียงใหม่ และข้อความสงวนลิขสิทธิ์ ใช้ได้ครบทั้งภาษาไทย อังกฤษ เมียนมา และจีน
- บนมือถือ footer จะเรียงกึ่งกลางและเว้นที่ด้านล่างไว้ ปุ่มเกมลอยมุมขวาล่างจึงไม่บังข้อความ

---

## ฝั่งทีม (technical changelog)

### ย้ายโลโก้ไปเป็น footer เครดิต (PR #271, merge commit `452e7ec`)

- **Mobile/UI:** เอา `<img>` โลโก้ออกจาก brand ใน `src/components/layout/StudentNav.tsx` และเพิ่ม `src/components/layout/StudentFooter.tsx` ซึ่ง mount ครั้งเดียวจาก `src/app/dashboard/layout.tsx` (ไฟล์ใหม่) และ `src/app/battle/layout.tsx` แทนที่จะให้แต่ละหน้าใส่เองแบบ `StudentNav` หน้า `/dashboard/profile` จึงได้ footer ไปด้วย
- **i18n:** เพิ่ม key `footerCredit` และ `footerRights` ครบ EN/TH/MM/CN เพราะเป็นหน้าฝั่งนักศึกษา ข้อความ MM/CN ควรให้เจ้าของภาษาช่วยตรวจอีกรอบ
- **Performance:** footer ใช้ `public/smocamt-logo-footer.png` ขนาด 288px (31 KB) ที่ย่อมาจากไฟล์ต้นฉบับ 2006px (424 KB) และโหลดแบบ lazy
- **เวอร์ชัน:** `package.json` ปรับเป็น 2.20.1 ให้ตรงกับ tag
- **DB/migration:** ไม่มีการแก้ schema และไม่ต้อง migrate
- **ตรวจสอบแล้ว:** `npm run build` ผ่าน unit test 352 ตัวผ่าน และ eslint ของไฟล์ที่แก้ไม่มี error (มีแค่ warning `<img>` แบบเดียวกับโค้ดเดิม) ยังไม่ได้ดูหน้าจริงบน prod

---

อัปเดตรอบนี้รวม PR #271 (ย้ายโลโก้ SMO CAMT จากแถบเมนูไปเป็น footer เครดิต branch `feat/student-footer-credit` merge commit `452e7ec`) ตัดแพ็กเกจเป็น **tag/release v2.20.1** สรุปวันที่ 9 ต.ค. 69

# ActiveCAMT v2.20.2 🎉

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **footer มีเครดิตผู้ทำแล้ว** ต่อจากข้อความสงวนลิขสิทธิ์จะมี "แนวคิดโดย ณัฐภัทร จักขุเรือง" และ "พัฒนาโดย ภูริ แสงนวกิจ" โดยชื่อผู้พัฒนากดไปดู GitHub ได้ ถ้าเปิดเว็บเป็นภาษาไทยจะเห็นชื่อภาษาไทย ส่วนภาษาอังกฤษ เมียนมา และจีนจะเห็นชื่อภาษาอังกฤษ
- บนมือถือเครดิตแต่ละบรรทัดจะเรียงลงมาทีละบรรทัด อ่านง่ายไม่ติดกัน

---

## ฝั่งทีม (technical changelog)

### เครดิตผู้คิดและผู้พัฒนาใน footer (PR #272, merge commit `8ba168c`)

- **Mobile/UI:** แถวลิขสิทธิ์ใน `src/components/layout/StudentFooter.tsx` เปลี่ยนเป็น flex แยกแต่ละเครดิตด้วยจุด และลิงก์ชื่อผู้พัฒนาไปที่ `https://github.com/daydeda` (`rel="noopener noreferrer"`) บนจอไม่เกิน 1023px จะเรียงเป็นคอลัมน์และซ่อนจุดคั่น
- **i18n:** เพิ่ม key `footerConceptBy`, `footerDevBy`, `footerConceptName`, `footerDevName` ครบ EN/TH/MM/CN โดยชื่อเก็บเป็น key ด้วยเพื่อให้ TH แสดงชื่อไทยได้
- **เวอร์ชัน:** `package.json` ปรับเป็น 2.20.2 ให้ตรงกับ tag
- **DB/migration:** ไม่มีการแก้ schema และไม่ต้อง migrate
- **ตรวจสอบแล้ว:** `npm run build` ผ่าน unit test 352 ตัวผ่าน และ eslint ของไฟล์ที่แก้ไม่มี error ยังไม่ได้ดูหน้าจริงบน prod
