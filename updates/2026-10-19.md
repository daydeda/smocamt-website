## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ไฟล์ส่งออก .xlsx ของสินค้ามีรูปสลิปแล้ว** กดปุ่มส่งออกที่สินค้าแล้วจะได้ชีต "Slips" ที่แสดงรูปสลิปของแต่ละคำสั่งซื้อ พร้อมชื่อ รหัสนักศึกษา สถานะ ยอดรวม ผลตรวจสลิปอัตโนมัติ และลิงก์ไปหน้าตรวจสอบของธนาคาร ชีต Orders เดิมยังเรียงและกรองได้ตามปกติ ส่วนชีต Slips มีหมายเหตุว่าห้ามเรียง เพราะรูปจะไม่เลื่อนตามแถว ให้ดูจาก Order ID ที่อยู่ข้างรูป
- **ระบบตรวจยอดเงินในสลิปให้อัตโนมัติ** ตอนนักศึกษาอัปโหลดสลิป ระบบจะอ่านตัวเลขในสลิป ถ้าอ่านได้แต่ไม่มียอดไหนตรงกับยอดที่ต้องชำระ คำสั่งซื้อนั้นจะมีป้ายเตือน "ยอดไม่ตรง" ในหน้าตรวจคำสั่งซื้อและกรองดูเฉพาะที่มีป้ายเตือนได้ ระบบแค่เตือนให้ตรวจเองก่อนอนุมัติ ไม่ได้ปฏิเสธคำสั่งซื้อให้ และถ้าอ่านสลิปไม่ออกจะไม่มีป้ายเตือน
- **ไฟล์ส่งออกไม่กินพื้นที่เซิร์ฟเวอร์** ไฟล์ถูกสร้างตอนกดดาวน์โหลดแล้วส่งให้เลย ไม่ได้เก็บไว้ ขนาดไฟล์เพิ่มประมาณ 80KB ต่อสลิป
- ประธานชมรม/สาขาและผู้ขายเห็นรูปสลิปในไฟล์เฉพาะคำสั่งซื้อที่เป็นสินค้าของตัวเองทั้งหมด เหมือนสิทธิ์ดูสลิปเดิม

## ฝั่งทีม (technical changelog)

### รูปสลิปในไฟล์ส่งออกและตรวจยอดเงินในสลิป (PR #277, merge commit `cfa442c`)

- **Export:** เพิ่ม `GET /api/admin/shop/products/[id]/export` สร้างไฟล์ฝั่งเซิร์ฟเวอร์ด้วย `exceljs` (SheetJS ที่ใช้ในที่อื่นฝังรูปไม่ได้) เหมือนรายงานรูปรางวัล ย่อสลิปเหลือด้านยาว 800px แปลงเป็น jpeg จำกัด 500 สลิปต่อไฟล์ และลบ route เดิม `/api/admin/shop/products/[id]/orders` ที่ใช้เฉพาะการส่งออกนี้ พร้อมแก้คอมเมนต์อ้างอิงใน `migrate.ts` ฝั่งไคลเอนต์ดาวน์โหลดไฟล์จาก route ใหม่แทนการสร้างเองในเบราว์เซอร์
- **สิทธิ์เข้าถึง:** ใช้ `resolveShopAccess` และ `isProductOwnedByScope` เหมือนเดิม และสลิปจะแสดงให้ผู้ใช้ที่มีขอบเขตเฉพาะคำสั่งซื้อที่ `fullyOwned` ตามกฎของ route ดูสลิป
- **PDPA:** audit log ของการส่งออกบันทึกจำนวนรูปสลิปที่ฝังด้วย และเป็นแบบ await ถ้าบันทึกไม่ได้จะไม่ส่งไฟล์ให้
- **OCR:** เพิ่ม `src/lib/shop-slip-amount.ts` ใช้ `tesseract.js` กับโมเดลภาษาอังกฤษใน `node_modules` (ไม่ดึงจาก CDN) ดึงตัวเลขรูปแบบเงินทั้งหมดจากสลิปเป็นหน่วยสตางค์ แล้วเทียบกับยอดรวมของคำสั่งซื้อ ใช้ worker เดียวต่อคิว มี timeout 20 วินาที และไม่ throw ถ้าพัง
- **Token:** `signSlipMeta`/`verifySlipMeta` เพิ่มช่องยอดที่อ่านได้ (ลงลายมือชื่อรวมอยู่ใน HMAC เดิม) token เก่าแบบ 5 ช่องจะถูกปฏิเสธ แล้วระบบกลับไปอ่านสลิปจากที่เก็บเหมือนเดิม
- **Flag:** `slip_flag` เพิ่มค่า `amount_mismatch` ตั้งตอนสร้างคำสั่งซื้อหลังรู้ยอดสุทธิ โดย `duplicate_*` และ `no_qr` มาก่อนเสมอ เพิ่มข้อความ EN/TH ในหน้าแอดมิน
- **Config/Docker:** เพิ่ม `tesseract.js` ใน `serverExternalPackages` ของ `next.config.ts` และเพิ่ม dependency `tesseract.js`, `@tesseract.js-data/eng` ทำให้ image ใหญ่ขึ้นราว 56MB
- **ทำความสะอาด:** ลบโฟลเดอร์ `.agents` ที่ไม่ใช้แล้ว และเพิ่ม `docs/workload/`, `docs/manual-tor-srs/`, `.archify/` ใน `.gitignore`
- **เวอร์ชัน:** `package.json` และ `package-lock.json` ปรับเป็น 2.22.0 ใน branch ของ PR ให้ตรงกับ tag
- **DB/migration:** ไม่มีการแก้ schema และไม่ต้อง migrate
- **ตรวจสอบแล้ว:** `npm run build` ผ่าน, `npm test` 360 ตัวผ่าน และ `npm run lint` ไม่มี error ใหม่ (มี error เดิมหนึ่งจุดใน `battle-flow.test.ts`) ทดสอบ OCR ในเซิร์ฟเวอร์ Next จริงด้วยสลิปจำลองแล้ว แต่ยังไม่ได้ทดสอบกับสลิปธนาคารจริงและยังไม่ได้ทดสอบ flow สั่งซื้อทั้งหมดกับฐานข้อมูล
