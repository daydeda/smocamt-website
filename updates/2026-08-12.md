# อัปเดต ActiveCAMT ประจำวันที่ 12 ส.ค. 69

สรุปสำหรับวันที่ 12 ส.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **เมนูนักศึกษาปรับดีไซน์ใหม่ทั้งหมด** เดิมปุ่มเมนูเรียงยาวเต็มแถบบน ตอนนี้เหลือแค่ปุ่มหลักที่ใช้บ่อย ๆ (หน้าหลัก ปฏิทิน บัตรประจำตัว) แล้วเพิ่มปุ่ม **"Services"** ใหม่เข้ามา กดแล้วจะเปิดเมนูรวมทุกฟีเจอร์ให้ (กระดานคะแนนบ้าน ประวัติกิจกรรม ร้านค้า บ้านของฉัน โปรไฟล์ ฯลฯ) เผื่อที่ไว้สำหรับฟีเจอร์ใหม่ ๆ ที่จะค่อย ๆ เพิ่มเข้ามาในอนาคต เช่น ระบบร้องเรียน (VOC) และพื้นที่การเรียน ซึ่งตอนนี้ขึ้นป้าย "เร็ว ๆ นี้" ไว้ล่วงหน้าแล้ว เมนูจะได้ไม่รกจนหาของเดิมไม่เจอ
- แก้ข้อความแจ้งเตือนตอนกรอกรหัสนักศึกษาไม่ตรงกับคณะแล้ว เปลี่ยนจาก "ไม่ตรงกับคณะ CAMT" เป็นชื่อเต็ม "วิทยาลัยศิลปะ สื่อ และเทคโนโลยี" พร้อมเปลี่ยนช่องทางติดต่อจาก "เจ้าหน้าที่" เป็น **IG: smocamt.official** ให้ติดต่อได้ตรงจุดขึ้น (แก้ทั้งหน้าลงทะเบียนครั้งแรกและหน้าแก้โปรไฟล์)

---

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **เมนูฝั่งแอดมินเพิ่มปุ่มค้นหาด้านบน** กด **⌘K** (หรือ Ctrl+K บน Windows) หรือกดปุ่ม "Search" ที่หัวเมนูก็ได้ แล้วพิมพ์ชื่อหน้าที่ต้องการ เช่น "shop" หรือ "audit" ไม่ต้องไล่เลื่อนหาในเมนูซ้ายอีกต่อไป เร็วขึ้นมากสำหรับคนที่ใช้ระบบทุกวัน
- **เมนูซ้ายของแอดมินยุบ/ขยายเป็นหมวดได้แล้ว** (สำหรับ role ที่มีเมนูเยอะ อย่าง super_admin หรือ admin) กดที่หัวข้อหมวด เช่น "EVENTS" หรือ "COMMUNITY" เพื่อซ่อนหรือแสดงได้เลย ระบบจะจำไว้ให้ด้วย ครั้งหน้าเข้ามาก็ยังยุบอยู่เหมือนเดิม ส่วนหมวดที่มีหน้ากำลังเปิดอยู่จะขยายให้เองเสมอ ไม่มีทางถูกซ่อนจนหาไม่เจอแน่นอน ส่วน role ที่มีเมนูน้อยอยู่แล้ว เช่น scanner-only ประธานชมรม/สาขา หรือฝ่ายทะเบียน จะไม่เห็นการเปลี่ยนแปลงนี้เลย เมนูเหมือนเดิมทุกอย่าง

## ฝั่งทีม (technical changelog)

### Config-driven nav redesign นักศึกษา + แอดมิน (PR #213, #214)

- **Mobile/UI (นักศึกษา):** แยก nav data ออกจาก component มาไว้ที่ `src/lib/nav-config.ts` (pure data/functions) ให้ทั้งแถบเมนูบนและ Services launcher อ่านข้อมูลจากแหล่งเดียวกัน เมื่อก่อนมี `primaryLinks`/`secondaryLinks` แยกกันสองชุด ซึ่งหลุด sync กันได้ง่าย ๆ (ปุ่มบางอันเคยกดจากมือถือไม่ถึงมาก่อน)
- Services launcher (`ServicesLauncher.tsx`) เป็น overlay ตัวใหม่ บนมือถือเปิดเป็นลิ้นชักซ้าย ส่วนจอใหญ่เปิดเป็น grid กลางจอ มี focus-trap กด Escape ปิดได้ และคืน focus กลับไปที่ปุ่มเดิมเมื่อปิดครบ (เป็น a11y pattern แรกของโปรเจกต์ที่ทำแบบนี้)
- **Mobile/UI (แอดมิน):** sidebar แอดมินก็แยก data ออกมาเป็น `src/lib/admin-nav-config.ts` เหมือนกัน โดย RBAC ต่อรายการ (scanner-only, major_president-only ฯลฯ) ย้ายจาก logic ที่ฝังอยู่ใน component มาเป็น predicate ต่อ item แทน **คัดลอกพฤติกรรมเดิมทุกเส้นแบบคำต่อคำ ไม่ได้เขียนใหม่ตามความเข้าใจ** แล้ว pin ไว้ด้วยเทส 13 เคส (`admin-nav-config.test.ts`) ให้ครอบทุก role/position ที่มีในระบบ
- เพิ่ม **Cmd/Ctrl+K command palette** (`AdminCommandPalette.tsx`) ให้แอดมินกดหาเมนูได้เร็วขึ้น ไม่ต้องเลื่อนหา เหตุผลที่เลือก palette แทน launcher-grid แบบฝั่งนักศึกษาคือ แอดมินเป็น user ที่ใช้งานบ่อยและชำนาญอยู่แล้ว ต้องการความเร็วมากกว่าการเรียกดูแบบ casual
- sidebar แอดมินเพิ่ม **group ที่ยุบ/ขยายได้** พร้อมจำสถานะไว้ให้ (`localStorage`) แต่เปิดใช้เฉพาะ role ที่มีเมนูเกิน 10 รายการเท่านั้น (ปกติจะเป็น super_admin กับ admin) ส่วน role ที่เมนูน้อยอยู่แล้ว เช่น scanner-only ประธานชมรม หรือฝ่ายทะเบียน ยังเห็นเมนูแบบเดิมเป๊ะ ไม่มีอะไรเปลี่ยน
- ทั้งสองฝั่งเพิ่ม group ใหม่ **Feedback/VOC** และ **Learning/Study** ไว้ล่วงหน้าด้วย ตอนนี้ยังไม่มีหน้าเพจจริง ขึ้นเป็นแถบ "เร็ว ๆ นี้" ที่กดไม่ได้ก่อน เผื่อโครงสร้างเมนูไว้รองรับฟีเจอร์ในอนาคต จะได้ไม่ต้องรื้อเมนูใหม่อีกรอบ
- **แก้บัคจริงที่เจอระหว่างทำงาน:** effect ที่ auto-focus ตอนเปิด overlay (ทั้ง launcher และ palette) แข่งจังหวะกับ hydration-safe gate อยู่ ทำให้ focus ไม่เคยลงจริงตั้งแต่ pattern นี้ถูกสร้างขึ้นมา (เงียบ ๆ ไม่มี error ให้เห็นด้วย) แก้โดยแยก effect การ focus ออกมาต่างหาก แล้ว key ด้วย `hasOpened` แทนที่จะใช้ `open` เฉย ๆ
- **แก้ UX ที่เจอตอน mobile review:** แถว "เร็ว ๆ นี้" ที่มีแค่รายการเดียวในกลุ่ม (เช่น Feedback) เดิมอยู่ใน grid 3 คอลัมน์ เลยเหลือช่องว่างข้าง ๆ ดูเหมือนเมนูหายไป ตอนนี้เปลี่ยนให้แถวนี้กางเต็มความกว้างแทนแล้ว
- ตรวจสอบแล้วด้วย `npm test` (ผ่านหมด 135 เคส รวมเทสใหม่), `npm run lint`, `npm run build`, และ Playwright pass ทั้งมือถือ จอใหญ่ และหลาย role พร้อมให้ `pdpa-access-guard` reviewer ตรวจฝั่งแอดมินด้วย ไม่พบ regression ของสิทธิ์เข้าถึงเทียบกับ logic เดิม

### ข้อความ faculty-mismatch แก้ใหม่ (PR #212)

- **Mobile/UI:** เปลี่ยนคำในหน้าลงทะเบียน (`OnboardingClient.tsx`) และหน้าแก้โปรไฟล์ (`dashboard/profile/page.tsx`) ทั้ง TH และ EN เดิมอ้างชื่อ "คณะ CAMT" ซึ่งไม่ตรงกับชื่อทางการ แล้วให้ติดต่อ "เจ้าหน้าที่" เฉย ๆ ตอนนี้ระบุชื่อวิทยาลัยเต็มและช่องทาง IG ที่ติดต่อได้จริงแล้ว

### แก้ super_admin หายหลัง seed (PR #215)

- **สิทธิ์เข้าถึง:** `seed.ts` เดิมอัปเดตแค่คอลัมน์ `role` ตอน promote ผู้ใช้เป็น super_admin แต่ `effectiveRoles()` ซึ่งเป็นตัวตัดสินสิทธิ์จริง จะใช้ `roles[]` ก่อนเสมอถ้ามีค่าอยู่ ทำให้ผู้ใช้ที่มี `roles[]` เดิมจากตอน onboarding (เช่น `["student"]`) จะยังไม่เห็น Admin Panel ทั้งที่ `role` บอกว่าเป็น super_admin แล้วก็ตาม เจอปัญหานี้จากบัญชีจริงระหว่าง dev รอบนี้เลย แก้ให้ทั้งสอง branch (ทั้งตอน update ผู้ใช้เดิมและตอนสร้างใหม่) sync `roles[]` ไปพร้อมกันแล้ว
