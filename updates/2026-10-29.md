# ActiveCAMT v2.38.0 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 29 ต.ค. 69

สรุปสำหรับวันที่ 29 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **กิจกรรมขึ้นมาอยู่บนสุดในมือถือและแท็บเล็ต:** หน้าแดชบอร์ดไม่ต้องเลื่อนนานก่อนจะเห็นกิจกรรม ส่วนหัวเหลือบรรทัดเดียว แสดงคำทักทาย อันดับบ้าน คะแนน ปุ่มบัตรประจำตัวดิจิทัล และปุ่มลูกโลกสำหรับเปลี่ยนภาษา
- **มุมมองรายการแบบกระชับ:** กิจกรรมแสดงเป็นแถวพร้อมรูปโปสเตอร์ แบ่งเป็นวันนี้ สัปดาห์นี้ และที่จะมาถึง มีปุ่มกรองกิจกรรม และกิจกรรมที่จบแล้วซ่อนไว้ก่อน กดดูได้เมื่อต้องการ
- **อ่านรายละเอียดก่อนลงทะเบียน:** กิจกรรมที่มีรายละเอียดจะมีปุ่มอ่านเพิ่มเติมก่อนเข้าร่วม ทั้งในการ์ดและในรายการ
- **ประกาศสำคัญกดดูได้:** บนมือถือแสดงเป็นการ์ดสั้น ๆ มีปุ่มอ่านเพิ่มเติม แตะเพื่อดูประกาศฉบับเต็มได้
- **กิจกรรมแบบส่งหลักฐาน:** ปุ่มในการ์ดและรายการจะพาไปหน้าส่งหลักฐานของวันนี้โดยตรง
- **เปลี่ยนภาษาบนมือถือได้ง่ายขึ้น:** กดปุ่มลูกโลกที่บรรทัดคำทักทาย หรือเปิดเมนูบริการ
- มุมมองการ์ดหรือรายการที่เลือกไว้จะถูกจำไว้ในอุปกรณ์นั้น

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ไม่มีการเปลี่ยนแปลงสิทธิ์หรือเมนูผู้ดูแล** การปรับปรุงนี้เกี่ยวข้องกับหน้าแดชบอร์ดของนักศึกษาเท่านั้น

## ฝั่งทีม (technical changelog)

- **UI/Dashboard:** เพิ่ม `CompactHeader`, `EventRow` และ `RegisterButton` แยกจาก `EventsColumn` และใช้ตรรกะสถานะการลงทะเบียนร่วมกันผ่าน `src/lib/events/register-state.ts` เพื่อให้ปุ่มในการ์ด ในรายการ และในป๊อปอัปไม่คลาดเคลื่อนกัน
- **Utils:** เพิ่ม `src/lib/events/event-when.ts` สำหรับจัดรูปแบบวันเวลาตามเขตเวลาของกรุงเทพฯ พร้อมชุดทดสอบ
- **Theme:** แทนที่สคริปต์ตั้งธีมแบบ `<script>` ดิบด้วย `ThemeInitScript` เพื่อไม่ให้ React แจ้งเตือนตอนเรนเดอร์ฝั่งไคลเอนต์ และยังคงธีมที่บันทึกไว้เมื่อหน้าถูกสร้างใหม่
- **i18n:** เพิ่มคีย์ของแดชบอร์ดและประกาศในภาษาไทย อังกฤษ พม่า และจีน
- ไม่มีการเปลี่ยน schema หรือ migration

อัปเดตรอบนี้คือ v2.38.0 (commit 68300cf) ซึ่งทำให้กิจกรรมขึ้นมาอยู่บนสุดในมือถือและแท็บเล็ต
