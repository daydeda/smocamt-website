# ActiveCAMT v2.39.2 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 31 ต.ค. 69

สรุปสำหรับวันที่ 31 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **กิจกรรมที่จบแล้วลงทะเบียนไม่ได้อีก:** ถ้ากิจกรรมผ่านเวลาสิ้นสุดไปแล้ว ปุ่มจะขึ้นว่า "Event Ended" เป็นสีเทาและกดไม่ได้ ไม่มีปุ่มลงทะเบียนหรือปุ่มเข้าคิวรอสำรองให้กดอีก
- **เมนู Services บนมือถือขนาดช่องเท่ากันแล้ว:** ทุกปุ่มมีความสูงเท่ากัน แม้ชื่อเมนูจะยาวหรือเป็นหลายภาษา

## ฝั่งทีม (technical changelog)

- **Registration:** `getRegisterState` คืนค่า `ended` ให้ผู้ที่ยังไม่ได้ลงทะเบียนเมื่อกิจกรรมจบแล้ว พร้อม `blocked` และ `greyed` เดิมทีจะเป็นแบบนี้ก็ต่อเมื่อมีเวลาปิดรับสมัคร
- **API:** `POST /api/events/[id]/register` ตอบ 403 เมื่อกิจกรรมจบแล้ว ยกเว้น event staff และแอดมิน
- **UI/Mobile:** `ServicesLauncher` ใช้ `grid-auto-rows` ความสูงคงที่ คอลัมน์ `minmax(0, 1fr)` และจำกัดชื่อเมนูที่ 2 บรรทัด
- ไม่มีการเปลี่ยน schema หรือ migration

อัปเดตรอบนี้คือ v2.39.2 (commit 4756c08) ซึ่งแก้ปุ่มลงทะเบียนของกิจกรรมที่จบแล้วและปรับขนาดปุ่มเมนู Services

# ActiveCAMT v2.40.0 🎉

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **หน้าสแกนของเจ้าหน้าที่ใช้หน้าตาเดียวกับหน้าแอดมิน:** เจ้าหน้าที่ที่เข้าหน้าสแกนจากเมนู Scan จะเห็นแท็บ Check-in, Scan Score, Prize, Shop และ Tags ตามสิทธิ์ของตัวเอง และเปิดมาที่ Check-in ก่อน ไม่ถูกพาไปสแกนป้ายทรัพย์สินทันที
- **นักศึกษาทั่วไปไม่เปลี่ยน:** ยังสแกนป้ายทรัพย์สินเพื่อดูว่าใครเป็นเจ้าของได้เหมือนเดิม

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **หน้าแอดมินทุกหน้าหน้าตาเป็นชุดเดียวกัน:** ปรับหน้าสร้างกิจกรรม ตัวกรองนักศึกษา และตัวเลือก Major ให้ระยะห่าง มุมโค้ง และปุ่มลอย Discard/Create Event สมดุลขึ้น ลูกศรของ dropdown อยู่ในกล่องอย่างเหมาะสมทุกหน้า
- **ปุ่มลบในหน้า Students อยู่ติดปุ่ม Medical record:** ไม่มีช่องว่างกว้างเกินไปอีก
- **ยกเลิกบทบาท Registration Staff และ Event Organizer:** งานของฝ่ายลงทะเบียนย้ายไปอยู่ที่บทบาท SMO ที่มีตำแหน่ง Registration ส่วน ANUSMO ที่มีตำแหน่ง Registration ทำได้เฉพาะเช็กอินนักศึกษาเท่านั้น
- **ข้อมูลติดต่อฉุกเฉินในรายชื่อผู้เข้าร่วม:** ฝ่ายลงทะเบียนเห็นเฉพาะความสัมพันธ์และเบอร์โทร ไม่เห็นชื่อผู้ติดต่อ เหมือนระดับประธานชมรม
- **Super Admin เก็บบทบาทเสริมไว้ได้ และเห็นแท็บ Major** เหมือนแท็บ Clubs

## ฝั่งทีม (technical changelog)

- **สิทธิ์เข้าถึง:** ลบ `registration` และ `organizer` ออกจากทุก gate ใน `admin-access.ts`, `proxy.ts`, `auth.ts`, API routes และหน้า client เพิ่ม `isAnusmoRegistration` และ `canCheckInEveryEvent` ให้ ANUSMO + registration เช็กอินได้ทุกกิจกรรมแต่ไม่ผ่าน gate อื่น `isGlobalRegistrationPosition` เหลือเฉพาะ SMO
- **PDPA:** รายชื่อผู้เข้าร่วมระดับ registration ใช้ `redactEmergencyContacts` ส่วน export ยังเห็นเฉพาะสัญญาณทางการแพทย์ และทุกการเข้าถึงยังบันทึก audit log
- **DB/migration:** step 110 ใน `migrate.ts` แปลง role `registration` เป็น `smo` + ตำแหน่ง `registration` และตัด `organizer` โดยไม่ลบข้อมูล รันซ้ำได้ ตำแหน่งเก่าที่ค้างอยู่ของคนที่ไม่เคยเป็น SMO (เช่น finance) จะถูกแทนที่เป็น `registration` เพื่อไม่ให้ได้สิทธิ์ Finance โดยไม่ตั้งใจ ต้องรัน `npm run db:migrate:container` บน production
- **UI/Scanner:** `ScannerScreen` ใช้ร่วมกันทั้ง `/admin/scanner` และ `/dashboard/scan` เพิ่มแท็บ Tags แบบ lookup สำหรับคนที่จัดการป้ายไม่ได้ และแท็บ Tags ไม่เปิดกล้องเองแล้ว
- **UI/CSS:** `select.input` วาดลูกศรเองด้วย gradient ที่ใช้ token สีของธีม
- ไม่มีการเปลี่ยน schema

อัปเดตรอบนี้คือ v2.40.0 (commit 6ddb71f) ซึ่งรวมการปรับหน้าแอดมิน การยกเลิกบทบาท Registration และ Organizer และหน้าสแกนที่ใช้ร่วมกัน
