## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **เมนูนักศึกษาปรับดีไซน์ใหม่ทั้งหมด** — จากเดิมที่ปุ่มเมนูเรียงยาวเต็มแถบบน ตอนนี้เหลือแค่ปุ่มหลักที่ใช้บ่อย (หน้าหลัก, ปฏิทิน, บัตรประจำตัว) พร้อมปุ่ม **"Services"** ใหม่ กดแล้วเปิดเมนูรวมทุกฟีเจอร์ (กระดานคะแนนบ้าน, ประวัติกิจกรรม, ร้านค้า, บ้านของฉัน, โปรไฟล์ ฯลฯ) เผื่อพื้นที่ไว้สำหรับฟีเจอร์ใหม่ที่จะทยอยเพิ่ม (ระบบร้องเรียน/VOC, พื้นที่การเรียน — ขึ้น "เร็ว ๆ นี้" ไว้ล่วงหน้าแล้ว) โดยเมนูจะไม่รกจนหาของเดิมไม่เจอ
- แก้ข้อความแจ้งเตือนตอนกรอกรหัสนักศึกษาไม่ตรงกับคณะ — จาก "ไม่ตรงกับคณะ CAMT" เปลี่ยนเป็นชื่อเต็ม "วิทยาลัยศิลปะ สื่อ และเทคโนโลยี" พร้อมเปลี่ยนช่องทางติดต่อจาก "เจ้าหน้าที่" เป็น **IG: smocamt.official** ให้ติดต่อได้ตรงจุดขึ้น (แก้ทั้งหน้าลงทะเบียนครั้งแรกและหน้าแก้โปรไฟล์)

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **เมนูฝั่งแอดมินเพิ่มปุ่มค้นหาด้านบน** — กด **⌘K** (หรือ Ctrl+K บน Windows) หรือกดปุ่ม "Search" ที่หัวเมนู แล้วพิมพ์ชื่อหน้าที่ต้องการได้เลย (เช่น "shop", "audit") ไม่ต้องไล่เลื่อนหาในเมนูซ้าย เร็วกว่าเดิมมากสำหรับคนที่ใช้ระบบทุกวัน
- **เมนูซ้ายของแอดมินยุบ/ขยายเป็นหมวดได้แล้ว** (สำหรับ role ที่มีเมนูเยอะ เช่น super_admin/admin) — กดหัวข้อหมวด (เช่น "EVENTS", "COMMUNITY") เพื่อซ่อน/แสดง ระบบจะจำไว้ให้ครั้งหน้าเข้ามาก็ยังยุบอยู่ตามเดิม ส่วนหมวดที่มีหน้าที่กำลังเปิดอยู่จะขยายให้เองเสมอ ไม่มีทางถูกซ่อนจนหาไม่เจอ role ที่มีเมนูน้อยอยู่แล้ว (scanner-only, ประธานชมรม/สาขา, ฝ่ายทะเบียน) จะไม่เห็นการเปลี่ยนแปลงนี้ เมนูเหมือนเดิมทุกอย่าง

## ฝั่งทีม (technical changelog)

### Config-driven nav redesign — นักศึกษา + แอดมิน (PR #213, #214)

- **Mobile/UI (นักศึกษา):** แยก nav data ออกจาก component เป็น `src/lib/nav-config.ts` (pure data/functions) ให้ทั้งแถบเมนูบนและ Services launcher อ่านจากแหล่งเดียวกัน — เดิมมี `primaryLinks`/`secondaryLinks` แยกกันสองชุดที่หลุด sync ได้ง่าย (ปุ่มบางอันเคยกดจากมือถือไม่ถึง)
- Services launcher (`ServicesLauncher.tsx`) เป็น overlay ใหม่ — มือถือเปิดเป็นลิ้นชักซ้าย, จอใหญ่เปิดเป็น grid กลางจอ, มี focus-trap/Escape-to-close/คืน focus กลับปุ่มเดิมตอนปิดครบ (a11y pattern แรกของโปรเจกต์ที่ทำแบบนี้)
- **Mobile/UI (แอดมิน):** sidebar แอดมินก็แยก data ออกมาเป็น `src/lib/admin-nav-config.ts` เหมือนกัน — RBAC ต่อรายการ (scanner-only, major_president-only, ฯลฯ) ย้ายจาก logic ฝังใน component มาเป็น predicate ต่อ item, **คัดลอกพฤติกรรมเดิมทุกเส้นแบบคำต่อคำ** ไม่ใช่เขียนใหม่ตามความเข้าใจ — pin ไว้ด้วยเทส 13 เคส (`admin-nav-config.test.ts`) ครอบทุก role/position ที่มีในระบบ
- เพิ่ม **Cmd/Ctrl+K command palette** (`AdminCommandPalette.tsx`) ให้แอดมินกดหาเมนูได้เร็วขึ้นแทนการเลื่อนหา — เหตุผลที่เลือก palette แทน launcher-grid แบบฝั่งนักศึกษา: แอดมินเป็น user ที่ใช้บ่อย/ชำนาญ ต้องการความเร็ว ไม่ใช่การเรียกดูแบบ casual
- sidebar แอดมินเพิ่ม **group ที่ยุบ/ขยายได้** พร้อมจำสถานะไว้ (`localStorage`) แต่เปิดใช้เฉพาะ role ที่มีเมนูเกิน 10 รายการ (ปกติคือ super_admin/admin เท่านั้น) — role แคบ ๆ อย่าง scanner-only/ประธานชมรม/ฝ่ายทะเบียนยังเห็นเมนูแบบเดิมเป๊ะ ไม่มีอะไรเปลี่ยน
- ทั้งสองฝั่งเพิ่ม group ใหม่ **Feedback/VOC** และ **Learning/Study** ไว้ล่วงหน้า — ยังไม่มีหน้าเพจจริง ขึ้นเป็นแถบ "เร็ว ๆ นี้" ที่กดไม่ได้ เผื่อ IA ไว้รับฟีเจอร์ในอนาคตโดยไม่ต้องรื้อเมนูอีกรอบ
- **แก้บัคจริงที่เจอระหว่างทำ:** effect ที่ auto-focus ตอนเปิด overlay (ทั้ง launcher และ palette) แข่งจังหวะกับ hydration-safe gate อยู่ ทำให้ focus ไม่เคยลงจริง (เงียบ ๆ ไม่ error) ตั้งแต่ pattern นี้ถูกสร้างขึ้น — แก้โดยแยก effect การ focus ออกมา key ด้วย `hasOpened` แทน `open` เฉย ๆ
- **แก้ UX ที่เจอตอน mobile review:** แถว "เร็ว ๆ นี้" ที่มีแค่รายการเดียวในกลุ่ม (เช่น Feedback) เดิมอยู่ใน grid 3 คอลัมน์แล้วเหลือช่องว่างข้าง ๆ ดูเหมือนเมนูหาย — เปลี่ยนให้แถวนี้กางเต็มความกว้างแทน
- ตรวจสอบด้วย `npm test` (135 ผ่านหมด รวมเทสใหม่), `npm run lint`, `npm run build`, Playwright pass ทั้งมือถือ/จอใหญ่/หลาย role, และรัน `pdpa-access-guard` reviewer สำหรับฝั่งแอดมิน (ไม่พบ regression ของสิทธิ์เข้าถึงเทียบกับ logic เดิม)

### ข้อความ faculty-mismatch แก้ใหม่ (PR #212)

- **Mobile/UI:** เปลี่ยนคำในหน้าลงทะเบียน (`OnboardingClient.tsx`) และหน้าแก้โปรไฟล์ (`dashboard/profile/page.tsx`) ทั้ง TH/EN — เดิมอ้างชื่อ "คณะ CAMT" (ไม่ตรงกับชื่อทางการ) และให้ติดต่อ "เจ้าหน้าที่" เฉย ๆ ตอนนี้ระบุชื่อวิทยาลัยเต็มและ IG ติดต่อจริง

### แก้ super_admin หายหลัง seed (PR #215)

- **สิทธิ์เข้าถึง:** `seed.ts` เดิมอัปเดตแค่คอลัมน์ `role` ตอน promote ผู้ใช้เป็น super_admin แต่ `effectiveRoles()` (ตัวตัดสินสิทธิ์จริง) จะใช้ `roles[]` ก่อนเสมอถ้ามีค่าอยู่ — ผู้ใช้ที่มี `roles[]` เดิมจากตอน onboarding (เช่น `["student"]`) จะยังไม่เห็น Admin Panel ทั้งที่ `role` บอกว่าเป็น super_admin แล้ว เจอจากบัญชีจริงระหว่าง dev ครั้งนี้ — แก้ให้ทั้งสอง branch (update ผู้ใช้เดิม / สร้างใหม่) sync `roles[]` ไปพร้อมกัน
