# ActiveCAMT v2.25.1 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 21 ต.ค. 69

สรุปสำหรับวันที่ 21 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **สลับโหมดสว่างกับโหมดมืดแบบค่อย ๆ เปลี่ยนสี** เดิมกดปุ่มแล้วหน้าจอเปลี่ยนทันที ซึ่งแสบตา โดยเฉพาะตอนใช้ในที่มืด ตอนนี้สีจะค่อย ๆ เลื่อนไปประมาณ 0.3 วินาที ดูนุ่มนวลและสบายตากว่าเดิม
- คนที่ตั้งค่าเครื่องให้ลดการเคลื่อนไหว (reduce motion) จะยังเห็นการเปลี่ยนแบบทันทีเหมือนเดิม

---

## ฝั่งทีม (technical changelog)

### Theme transition (v2.25.1, commit `e4ea79f`)

- **UI:** `applyTheme()` ใน `src/lib/theme.ts` เพิ่มคลาส `theme-transition` บน `<html>` นาน 350 ms แล้วลบออก ส่วน `globals.css` ใช้คลาสนี้ทำ transition ของสีพื้นหลัง ตัวอักษร เส้นขอบ ไอคอน และเงา เพื่อไม่ให้กระทบ hover/focus ปกติ
- **ไม่กระทบ:** สคริปต์ตั้งธีมก่อน paint ใน `layout.tsx` และการพิมพ์ ตั้ง `data-theme` ตรง ๆ จึงยังเปลี่ยนทันทีและไม่มี flash นอกจากนี้ `prefers-reduced-motion` จะข้ามแอนิเมชัน
- **ไม่มีการเปลี่ยน DB, PDPA หรือสิทธิ์เข้าถึง**
- **ตรวจสอบแล้ว:** `npm run build` และ `tsc` ผ่าน, `npm run lint` ไม่มี error ใหม่ (มี error เดิมหนึ่งจุดใน `battle-flow.test.ts`) ยังไม่ได้ทดสอบบนเบราว์เซอร์จริง

---

อัปเดตรอบนี้ push ตรงเข้า `main` โดยไม่เปิด PR (commit `e4ea79f`) ตัดแพ็กเกจเป็น **tag/release v2.25.1** สรุปวันที่ 21 ต.ค. 69

# ActiveCAMT v2.25.2 🎉

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **คำทักทายและหัวข้อ "กิจกรรมที่กำลังจะมาถึง" ค่อย ๆ เปลี่ยนสีตอนสลับโหมดสว่าง/มืด** รวมถึงชื่อที่เป็นสีไล่เฉด ไม่กระตุกเปลี่ยนทันทีเหมือนรอบก่อน
- **สระและวรรณยุกต์ภาษาไทยในชื่อไม่ถูกตัดแล้ว** เช่นชื่อ "ภูริ" จะเห็นสระ ิ และ ู ครบ แม้ตั้งภาษาแอปเป็นอังกฤษ
- ตัดเครื่องหมายจุลภาคหลังคำทักทายออก

## ฝั่งทีม (technical changelog)

### Theme fade และฟอนต์ไทย (v2.25.2, commit `290f2ae`)

- **Gradient:** `.gradient-text` ใช้ `@property --gt-from/--gt-to` เพื่อให้ transition ได้ และเพิ่ม `-webkit-text-fill-color` ในรายการ transition

- **ไม่มีการเปลี่ยน DB, PDPA หรือสิทธิ์เข้าถึง**
- **ตรวจสอบแล้ว:** `npm run build` และ `tsc` ผ่าน ยังไม่ได้ทดสอบบนเบราว์เซอร์จริง

# ActiveCAMT v2.26.0 🎉

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **หน้า "ของของฉัน" (My Items)** แสดงรายการสิ่งของที่ทีมงานผูกป้าย QR ไว้ให้ เช่น กระเป๋าสำหรับไปเทรคกิ้ง เปิดได้จากเมนู Services
- **ปุ่มสแกนบนแถบด้านบน** ข้างปุ่ม Digital ID กดแล้วสแกนป้ายบนสิ่งของได้ทันที ไม่ต้องกดหลายขั้นตอน เหมือนถามว่า "นี่ใช่ของฉันไหม"
- **สแกนป้ายแล้วเห็นเฉพาะข้อมูลที่จำเป็น** คือชื่อ รหัสนักศึกษา สาขา และชั้นปี เพื่อให้ส่งของคืนได้โดยไม่เปิดเผยข้อมูลส่วนตัวเกินจำเป็น เจ้าของป้ายจะเห็นข้อความว่า "นี่คือของคุณ"

---

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **สร้างกลุ่มป้ายทรัพย์สิน** เช่น "Bag for Trekking" แล้วสั่งสร้าง QR จำนวนเท่าไรก็ได้ โดยเลือกชุดตัวอักษรได้ เช่น SMO, ANU, STU จะได้เลขป้ายอย่าง SMO-014
- **พิมพ์ป้ายลงกระดาษ A4** เลือกได้ว่าหน้าละกี่ป้าย มีเส้นประให้ตัด และมีโลโก้ SMO, QR, เลขป้ายกับรหัสสั้นบนป้าย
- **ผูกป้ายกับนักศึกษาด้วยการสแกน Digital ID** สแกนได้ทั้งสองลำดับ คือสแกนนักศึกษาก่อนแล้วสแกนป้าย หรือสแกนป้ายก่อนแล้วสแกนนักศึกษา หากไม่สะดวกก็ค้นหาด้วยชื่อ รหัสนักศึกษา หรือเบอร์โทรได้ ผลการค้นหาขึ้นทันทีที่พิมพ์ ไม่ต้องกด Enter
- **เปลี่ยนเจ้าของหรือยกเลิกได้** เมื่อยกเลิก ป้ายจะว่างและนำกลับมาใช้ซ้ำได้
- **หน้า Scan รวมศูนย์** ทีมงานเลือกโหมดสแกนป้าย เช็กอิน รางวัล และร้านค้าได้ในหน้าเดียว กล้องทุกโหมดใช้กรอบสีขาวแบบเดียวกัน

---

## ฝั่งทีม (technical changelog)

### Property tags (v2.26.0, commit `d80ea84`)

- **DB/migration:** ตารางใหม่ `property_tag_groups` และ `property_tags` (migration `0048`) มี unique index ของ `(series, serial)` และเพิ่มขั้นตอนที่รันซ้ำได้อย่างปลอดภัยใน `migrate.ts` โดยไม่มีคำสั่งลบข้อมูล รัน `db:migrate:container` บน prod แล้วก่อน push
- **สิทธิ์เข้าถึง:** เพิ่ม `canManagePropertyTags` (super_admin, admin, organizer, registration, smo) ใน `admin-access.ts` ใช้ครบทุกชั้น คือ proxy, nav และ API ผ่าน `resolvePropertyTagStaff` ส่วน smo ที่จำกัดเฉพาะสแกนเนอร์เข้าหน้านี้ได้ และเปิด `/t/*` เป็นเส้นทางสาธารณะใน `proxy.ts` โดยหน้าจริงยังตรวจการล็อกอินเอง
- **PDPA:** หน้า `/t/<code>` คืนแค่ชื่อ รหัสนักศึกษา สาขา ชั้นปี และไม่คืน role จำกัด 30 ครั้งต่อนาทีต่อผู้ดู ตั้ง `noindex` ทุกการเพิ่ม เปลี่ยน หรือยกเลิกเจ้าของบันทึก audit log แบบ append-only ใน transaction เดียวกัน เจ้าหน้าที่เห็นเบอร์โทรแบบปิดบังบางส่วนเท่านั้น
- **การผูกป้าย:** endpoint ใหม่ `resolve-student` รับเฉพาะ token ของ Digital ID ที่เซ็นแล้วและยังไม่หมดอายุ ไม่รับ user id ตรง ๆ กล้องของแผงนี้สแกนทั้งเฟรมเพราะ QR ของ Digital ID หนาแน่นกว่า QR ป้าย และอ่านโค้ดเดิมซ้ำแค่ครั้งเดียว กันไม่ให้ยิง API ซ้ำทุกเฟรม รองรับ optimistic concurrency ผ่าน `expectedOwnerId`
- **Scan page:** แยก `ScannerScreen` ออกจาก `/admin/scanner` เพื่อฝังโหมดเช็กอินในหน้า Scan โดยไม่ต้องทำซ้ำ และใช้ `QrViewfinder` กับค่าสแกนกลางร่วมกันทุกกล้อง เพิ่ม `scan-modes.ts` คำนวณโหมดตามบทบาท
- **i18n:** ข้อความฝั่งแอดมินมีเฉพาะ EN/TH ส่วนฝั่งนักศึกษามีครบ 4 ภาษา
- **ตรวจสอบแล้ว:** `npm test` ผ่าน 411 รายการ, `npm run build` ผ่าน, `npm run lint` ไม่มี error ใหม่ (มี error เดิมหนึ่งจุดใน `battle-flow.test.ts`) ทดสอบด้วยกล้องจำลองเท่านั้น ยังไม่ได้ทดสอบกล้องจริงบนมือถือ

---

# ActiveCAMT v2.26.1 🎉

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ตารางป้ายแบ่งหน้าได้แล้ว** กลุ่มที่สร้างป้ายไว้เป็นพันป้ายไม่ต้องเลื่อนยาวอีกต่อไป เลือกได้ว่าจะดูหน้าละ 25, 50, 100 หรือ 200 ป้าย มีปุ่มก่อนหน้า ถัดไป และบอกว่ากำลังดูป้ายที่เท่าไรจากทั้งหมดกี่ป้าย
- **ลบกลุ่มป้ายได้** กดปุ่มถังขยะที่หน้ารายการกลุ่ม ระบบจะถามยืนยันก่อน แต่ถ้ายังมีป้ายที่มีเจ้าของอยู่ จะลบไม่ได้ เพราะป้ายนั้นติดอยู่กับของของนักศึกษาแล้ว ให้ยกเลิกเจ้าของก่อน หรือเก็บกลุ่มเข้าคลังแทน
- **ดาวน์โหลดแผ่นป้ายเป็น PDF ขนาด A4 ตรงเป๊ะ** เดิมพิมพ์จากเบราว์เซอร์โดยตรง แล้ว Safari ย่อขยายหน้าเอง ทำให้คอลัมน์ขวาขาดหาย มีหัวกระดาษท้ายกระดาษแทรก และแตกเป็นหลายหน้าเกินจริง ตอนนี้ได้ไฟล์ PDF ที่ขอบกระดาษ 10 มม. เท่ากันทุกด้าน QR คมชัด และเอาปุ่มพิมพ์จากเบราว์เซอร์ออกแล้วเพื่อไม่ให้สับสน

---

## ฝั่งทีม (technical changelog)

### Property tags (v2.26.1, commit `15b2163`)

- **UI:** แบ่งหน้าแบบฝั่ง client ใน `PropertyTagGroupClient` โดยหน้าปัจจุบันถูกจำกัดไม่ให้เกินหน้าสุดท้ายเมื่อกรองผลเหลือน้อยลง และรีเซ็ตกลับหน้าแรกเมื่อเปลี่ยนตัวกรองหรือคำค้น
- **สิทธิ์เข้าถึง:** เพิ่ม `DELETE /api/admin/property-tags/[id]` ผ่าน `resolvePropertyTagStaff` เหมือน route อื่น นักศึกษาได้ 401 และ id ที่ไม่ถูกต้องได้ 404
- **ลบกลุ่ม:** `deleteGroup` ทำใน transaction เดียว ล็อกแถวกลุ่ม นับป้ายที่มีเจ้าของ ถ้ามีจะตอบ 409 โดยไม่ลบ ถ้าไม่มีจะลบกลุ่มกับป้ายทั้งหมด (cascade) และบันทึก audit log แบบ append-only ในธุรกรรมเดียวกัน ป้ายที่พิมพ์ไปแล้วของกลุ่มที่ลบจะหาไม่เจออีก
- **PDF:** `src/lib/property-tag-pdf.ts` สร้าง PDF ในเบราว์เซอร์ด้วย `jspdf` และ `qrcode` วาด QR เป็นสี่เหลี่ยมเวกเตอร์ รวมโมดูลที่ติดกันเป็นแถวเดียวเพื่อให้ไฟล์เล็ก ใช้ตารางขนาดเดียวกับตัวอย่างบนหน้าจอ ตรวจแล้วว่าทุกหน้าเป็น A4 และขอบ 9.9 มม. ทั้งสี่ด้าน
- **Dependencies:** เพิ่ม `jspdf`, `qrcode` และ `@types/qrcode`
- **ไม่มีการเปลี่ยน DB schema หรือ PDPA** ข้อมูลที่แสดงบนป้ายยังเหมือนเดิม
- **ตรวจสอบแล้ว:** `npm test` ผ่าน 411 รายการ, `npm run build` ผ่าน, `npm run lint` ไม่มี error ใหม่ (มี error เดิมหนึ่งจุดใน `battle-flow.test.ts`) ยังไม่ได้ลองพิมพ์ PDF ลงกระดาษจริง
