## ฝั่งทีม (technical changelog)

- **Docker image:** ขนาดลดจาก 2.31 GB เหลือ 1.24 GB (ขนาดบีบอัดตอน push ลดจาก 565 MB เหลือ 263 MB) โดย image ใช้ `node_modules` เฉพาะ production (`npm ci --omit=dev` แยก stage), ลบ build cache ของ Turbopack ใน `.next/cache` ที่ไม่ได้ใช้ตอนรัน (ประมาณ 180 MB) และลบ native binary แบบ glibc ของ `@next/swc` กับ `sharp` ที่ไม่ได้ใช้บน Alpine ส่วน `tsx` ติดตั้งแบบ global ที่เวอร์ชัน 4.21.0 เพื่อให้ `npm run db:migrate:container` ใน Portainer console ยังใช้ได้เหมือนเดิม
- **Build speed:** `.dockerignore` ไม่รวม `docs/`, `updates/` และ `drizzle/` แล้ว เพราะ pattern `*.md` เดิมจับเฉพาะไฟล์ที่ root ทำให้การแก้ docs หรือ changelog ต้อง build ใหม่ทั้งหมด ตอนนี้ rebuild หลังแก้ docs ใช้เวลาประมาณ 1 วินาที และ `npm ci` ใช้ BuildKit cache mount
- **Backup:** `scripts/backup-db.mjs` และ `scripts/gdrive-get-refresh-token.mjs` เปลี่ยนจาก `googleapis` (203 MB) มาใช้ `@googleapis/drive` กับ `google-auth-library` โดยการทำงานเหมือนเดิม
- **ความปลอดภัย (dependencies):** อัปเดต `nodemailer` เป็น 10.2.1 ซึ่งปิดช่องโหว่ทั้งหมดที่ค้างจากรอบก่อน โดยใช้ `overrides` ให้ peer ของ `@auth/core` ใช้เวอร์ชันเดียวกัน (แอปใช้แค่ Google กับ Credentials provider) และ override `uuid` ของ `exceljs` เป็น 11.1.1 ผล `npm audit --omit=dev` เหลือ 0 รายการ ส่วนที่เหลือเป็นของ `drizzle-kit`/`esbuild` ฝั่ง dev ซึ่งไม่อยู่ใน image
- **Push notifications:** `enablePushNotifications` คืนเหตุผล `subscribe-failed` เมื่อ push service ของเบราว์เซอร์ปฏิเสธ และ log error จริงไว้ใน console ส่วน `PushNotificationToggle` จับ error แล้วรีเซ็ตสถานะ busy เหมือน `InstallPushPrompt` และ `announceNewEventIfOpen` ไม่ตัดผู้สร้างกิจกรรมออกจากผู้รับแล้ว
- **Lint:** แก้ `any` ใน `battle-flow.test.ts` ทำให้ `npm run lint` ไม่มี error แล้ว
- **ไม่มีการเปลี่ยน DB schema หรือ migration** และไม่แตะสิทธิ์การเข้าถึงหรือข้อมูลทางการแพทย์
- **ตรวจสอบแล้ว:** `npm run build`, `npm run lint` (0 error), `vitest` 476 tests ผ่าน และทดสอบ image ใหม่บนเครื่องกับ Postgres จริง ทั้งหน้าเว็บ, `/uploads`, `db:migrate:container` (รันซ้ำได้), `pg_dump`, `sharp`, `tesseract`, `nodemailer` และ `exceljs` ส่วน image ทดสอบบน arm64 เท่านั้น ยังไม่ได้ทดสอบ amd64 บนเครื่อง

อัปเดตรอบนี้รวม commit `ba1ebd8` (build(docker): slim the image, patch dependencies, harden push enable) และ release v2.32.4
