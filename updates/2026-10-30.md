# ActiveCAMT v2.38.1 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 30 ต.ค. 69

สรุปสำหรับวันที่ 30 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **รูปโปสเตอร์ในการ์ดกิจกรรมไม่ต้องกดแล้ว:** ที่หน้าแดชบอร์ด กดที่การ์ดเพื่อดูรายละเอียดกิจกรรมได้เลย รูปโปสเตอร์จึงไม่เปิดภาพเต็มจอแยกออกมาอีก เพราะซ้ำซ้อนกับการเปิดรายละเอียด

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ช่องรายละเอียดกิจกรรมกว้างขึ้นมาก:** ตอนสร้างหรือแก้ไขกิจกรรม ช่องเขียนรายละเอียดและตัวอย่างการแสดงผลแบบสดอยู่เต็มความกว้างของฟอร์ด วางคู่กันบนจอคอม และเรียงต่อกันบนมือถือ ตัวอักษรใหญ่ขึ้นและช่องสูงขึ้น ตรวจทานได้สบายกว่าเดิม
- **แก้ปัญหาปุ่มใส่สีไม่ทำงาน:** ปุ่มสีเดิมจะไม่ทำอะไรเลยถ้าเลือกสีเดิมซ้ำกับสีที่เลือกไว้ก่อนหน้า ตอนนี้มีแถบสีสำเร็จรูปให้กดใส่สีได้ทันที ใช้สีเดียวกับคำอื่นต่อได้ และยังมีปุ่มเลือกสีเองอยู่ท้ายแถว

## ฝั่งทีม (technical changelog)

- **UI/Admin events:** `EventFormPanel` ย้ายส่วน Description ออกจากคอลัมน์ขวาที่แคบ มาเป็นแถวเต็มความกว้างใต้ grid ของฟอร์ม พร้อมแถบสี `DESCRIPTION_COLORS` ที่ใช้ `onMouseDown` แบบ preventDefault เพื่อไม่ให้ข้อความที่เลือกไว้หลุด
- **Bug:** สาเหตุของปุ่มสีที่ไม่ทำงานคือ `<input type="color">` ที่ไม่ควบคุมค่า ซึ่งไม่ยิง `change` เมื่อค่าที่เลือกเท่ากับค่าปัจจุบัน ตัวเลือกสีเองจึงรีเซ็ตค่าหลังใช้งานทุกครั้ง ส่วน `ProposeEventSection` และ `RichTextEditor` ยังใช้รูปแบบเดิมอยู่
- **UI/Dashboard:** `EventsColumn` เอา `onExpand` ออกจากโปสเตอร์ในการ์ด
- **Repo:** เพิ่ม `docs/videos/` ใน `.gitignore`
- ไม่มีการเปลี่ยน schema หรือ migration

อัปเดตรอบนี้คือ v2.38.1 (commit 5e83517) ซึ่งขยายช่องรายละเอียดกิจกรรมและแก้ปุ่มใส่สี

# ActiveCAMT v2.38.2 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 30 ต.ค. 69 (รอบที่ 2)

สรุปรอบที่ 2 ของวันที่ 30 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ใส่สีตัวอักษรได้ต่อเนื่องในทุกหน้า:** แถบสีสำเร็จรูปที่เพิ่มในฟอร์มกิจกรรมรอบก่อน ตอนนี้ใช้ได้ในฟอร์มเสนอกิจกรรมของชมรมและสาขา หน้าประกาศ และช่องรายละเอียดในร้านค้าด้วย กดสีเดิมซ้ำกับคำอื่นได้โดยไม่ค้าง
- **ฟอร์มเสนอกิจกรรมมีช่องรายละเอียดแบบกว้าง:** ช่องเขียนและตัวอย่างการแสดงผลวางคู่กันเหมือนฟอร์มสร้างกิจกรรมของทีมงาน
- ปุ่มตัวหนาและลิงก์ในหน้าประกาศและร้านค้าแสดงเป็นภาษาไทยเมื่อเลือกภาษาไทย

## ฝั่งทีม (technical changelog)

- **UI/Refactor:** รวมโค้ดแก้ไขข้อความแบบมีรูปแบบจากสี่ที่เข้าด้วยกันที่ `RichTextEditor` โดยเพิ่ม layout แบบ `split`, `maxLength`, `lang`, `label` และ `hint` ส่วนแถบสีแยกเป็น `ColorSwatches` ใช้ร่วมกัน
- **Cleanup:** ลบ `injectMarkup` และ `textareaRef` ออกจาก `useAdminEventsPage` และลบตรรกะสลับตัวหนา ลิงก์ และสีที่ซ้ำกันใน `ProposeEventSection` กับ `AnnouncementEditor`
- ไม่มีการเปลี่ยน schema หรือ migration

อัปเดตรอบนี้คือ v2.38.2 (commit 44e5e5e) ซึ่งรวมตัวแก้ไขข้อความและแถบสีให้เป็นชุดเดียวกันทุกหน้า

# ActiveCAMT v2.39.0 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 30 ต.ค. 69 (รอบที่ 3)

สรุปรอบที่ 3 ของวันที่ 30 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **เห็นจำนวนที่นั่งตั้งแต่หน้ารายการ:** ที่แดชบอร์ดทั้งแบบรายการและแบบการ์ด แสดงจำนวนคนที่ลงทะเบียนต่อจำนวนที่รับ เช่น 12/50 พร้อมแถบความคืบหน้าบาง ๆ ไม่ต้องกดเข้าไปดูในการ์ดอีก
- **กิจกรรมเต็มแล้วยังเข้าคิวได้:** เมื่อที่นั่งเต็ม แถบจะเป็นสีเหลืองอำพันแทนสีแดง และขึ้นข้อความว่าเปิดรับรอคิวอยู่ พร้อมบอกจำนวนคนที่รออยู่ ทำให้รู้ว่ายังมีโอกาสได้ที่นั่ง
- **แจ้งเตือนกิจกรรมใหม่ถึงคนที่เข้าร่วมได้จริง:** เมื่อทีมงานเปิดกิจกรรมให้นักศึกษากลุ่มเพิ่ม เช่น ปลดล็อกจากเฉพาะปี 1 คนที่เพิ่งมีสิทธิ์จะได้รับแจ้งเตือน โดยคนที่ได้รับไปแล้วจะไม่ได้รับซ้ำ

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **ปุ่มส่งแจ้งเตือนอีกครั้ง:** ที่หน้ากิจกรรมของแอดมิน กิจกรรมที่ยังไม่เริ่มมีปุ่มส่งแจ้งเตือนซ้ำเป็นข้อความเตือนความจำ มีหน้าต่างยืนยันที่บอกจำนวนผู้รับ ส่งซ้ำได้ทุก 1 ชั่วโมง และใช้ได้เฉพาะ super admin กับ admin
- **super admin และ admin ได้รับแจ้งเตือนกิจกรรมใหม่เสมอ:** แม้กิจกรรมจะจำกัดชั้นปี บทบาท หรือสาขา ทำให้ทดสอบได้ว่าการแจ้งเตือนทำงานจริง

## ฝั่งทีม (technical changelog)

- **API/Push:** เพิ่ม `GET` และ `POST /api/admin/events/[id]/repush` ที่ตรวจสิทธิ์ super_admin/admin ฝั่งเซิร์ฟเวอร์ ใช้ advisory lock ต่อกิจกรรมเพื่อกันกดซ้ำพร้อมกัน และเขียน audit log ทุกครั้ง โดย cooldown 1 ชั่วโมงอ่านจาก audit log จึงไม่ต้องเพิ่มคอลัมน์
- **Push/Audience:** `getNewEventAudienceUserIds` ข้ามการตรวจสิทธิ์สำหรับ super_admin/admin ส่วน role อื่นยังตรวจเหมือนนักศึกษาปกติ และ `announceNewEventIfOpen` รับสถานะ eligibility ก่อนแก้ไข เพื่อส่งให้เฉพาะคนที่เพิ่งมีสิทธิ์
- **API/Events:** `/api/events` ส่ง `waitlistCount` เพิ่มเติม จาก query แบบ grouped ที่ cache 15 วินาทีเหมือน seat count
- **UI/Dashboard:** `EventRow` และ `quotaWalkInRows` แสดงจำนวนที่นั่งแบบ filled/capacity พร้อมแถบความคืบหน้า ใช้สี amber เมื่อเต็ม และเพิ่มข้อความแปลทั้งสี่ภาษา
- ไม่มีการเปลี่ยน schema หรือ migration

อัปเดตรอบนี้คือ v2.39.0 (commit 0aa31eb) ซึ่งเพิ่มปุ่มส่งแจ้งเตือนซ้ำและแสดงจำนวนที่นั่งกับคนรอคิวบนแดชบอร์ด
