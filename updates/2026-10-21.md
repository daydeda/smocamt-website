# ActiveCAMT v2.25.1 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 21 ต.ค. 69

สรุปสำหรับวันที่ 21 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **สลับโหมดสว่างกับโหมดมืดแบบค่อย ๆ เปลี่ยนสี** เดิมกดปุ่มแล้วหน้าจอเปลี่ยนทันที ซึ่งแสบตา โดยเฉพาะตอนใช้ในที่มืด ตอนนี้สีจะค่อย ๆ เลื่อนไปประมาณ 0.3 วินาที ดูนุ่มนวลและสบายตากว่าเดิม
- คนที่ตั้งค่าเครื่องให้ลดการเคลื่อนไหว (reduce motion) จะยังเห็นการเปลี่ยนแบบทันทีเหมือนเดิม

---

## ฝั่งทีม (technical changelog)

### Theme transition (v2.25.1, commit `e4ea79f`)

- **UI:** `applyTheme()` ใน `src/lib/theme.ts` เพิ่มคลาส `theme-transition` บน `<html>` นาน 350 ms แล้วลบออก ส่วน `globals.css` ใช้คลาสนี้ทำ transition ของสีพื้นหลัง ตัวอักษร เส้นขอบ ไอคอน และเงา เพื่อไม่ให้กระทบ hover/focus ปกติ
- **ไม่กระทบ:** สคริปต์ตั้งธีมก่อน paint ใน `layout.tsx` และการพิมพ์ ตั้ง `data-theme` ตรง ๆ จึงยังเปลี่ยนทันทีและไม่มี flash นอกจากนี้ `prefers-reduced-motion` จะข้ามแอนิเมชัน
- **ไม่มีการเปลี่ยน DB, PDPA หรือสิทธิ์เข้าถึง**
- **ตรวจสอบแล้ว:** `npm run build` และ `tsc` ผ่าน, `npm run lint` ไม่มี error ใหม่ (มี error เดิมหนึ่งจุดใน `battle-flow.test.ts`) ยังไม่ได้ทดสอบบนเบราว์เซอร์จริง

---

# ActiveCAMT v2.25.2 🎉

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **คำทักทายและหัวข้อ "กิจกรรมที่กำลังจะมาถึง" ค่อย ๆ เปลี่ยนสีตอนสลับโหมดสว่าง/มืด** รวมถึงชื่อที่เป็นสีไล่เฉด ไม่กระตุกเปลี่ยนทันทีเหมือนรอบก่อน
- **สระและวรรณยุกต์ภาษาไทยในชื่อไม่ถูกตัดแล้ว** เช่นชื่อ "ภูริ" จะเห็นสระ ิ และ ู ครบ แม้ตั้งภาษาแอปเป็นอังกฤษ
- ตัดเครื่องหมายจุลภาคหลังคำทักทายออก

---

## ฝั่งทีม (technical changelog)

### Theme fade และฟอนต์ไทย (v2.25.2, commit `290f2ae`)

- **UI:** หัวข้อ h1/h2 ของ dashboard ได้สี `var(--text-primary)` ตรง ๆ เพราะเดิมสืบทอดสีจาก body ทำให้ transition ซ้อนกันแล้วดูเหมือนเปลี่ยนช้า
- **Gradient:** `.gradient-text` ใช้ `@property --gt-from/--gt-to` เพื่อให้ transition ได้ และเพิ่ม `-webkit-text-fill-color` ในรายการ transition
- **Thai marks:** `background-clip: text` ตัดส่วนที่ล้นกล่อง จึงเพิ่ม padding กับ margin ติดลบเท่ากัน ตั้ง line-height 1.5 และ letter-spacing ปกติ ใช้กับทุกภาษาเพราะ `.lang-th` ไม่ทำงานเมื่อแอปเป็นอังกฤษแต่ชื่อเป็นไทย
- **ไม่มีการเปลี่ยน DB, PDPA หรือสิทธิ์เข้าถึง**
- **ตรวจสอบแล้ว:** `npm run build` และ `tsc` ผ่าน ยังไม่ได้ทดสอบบนเบราว์เซอร์จริง

---
