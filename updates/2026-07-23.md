## ฝั่งทีม (technical changelog)

### แก้ payload sync กิจกรรมให้พก imageUrl/imageUrls และ staffUserIds ไปด้วย (PR #201)

- **สาเหตุ:** `syncEventToSongsue` (`src/lib/songsue-sync.ts`) และ endpoint รับ sync ฝั่ง Songsue ไม่เคยรับ-ส่งฟิลด์แบนเนอร์ (`imageUrl`/`imageUrls`) หรือทีมงานประจำกิจกรรม (`staffUserIds`) เลยตั้งแต่เริ่มมี sync — ทั้งตอนสร้าง/แก้ไขกิจกรรม (`api/admin/events/route.ts`, `api/admin/events/[id]/route.ts`) และตอนกด resync ด้วยมือ (`api/admin/events/[id]/songsue-resync/route.ts`)
- ทั้ง 3 จุดที่ยิง sync ตอนนี้ resolve `staffUserIds` (user id ภายในของเราเอง) เป็น email/name ก่อนส่ง เพราะ user id ของเราไม่มีความหมายฝั่ง Songsue เลย พร้อมส่งค่าแบนเนอร์ปัจจุบันไปด้วยเสมอ
- ฝั่ง Songsue (`ActiveCamtSyncService.upsertExternalEvent`) resolve ทีมงานแต่ละคนด้วย email เป็น join key เดียวกับที่ sync การลงทะเบียนใช้อยู่แล้ว — ถ้ายังไม่มีบัญชี Songsue ที่ email นั้นจะสร้างบัญชีขั้นต่ำให้ (ไม่มี `pdpaConsent`, ไม่มีข้อมูลการแพทย์ใด ๆ) แล้วเขียน id ที่ resolve ได้ลง `events.staffUserIds` ของฝั่งนั้น
- payload ส่งค่า "ปัจจุบันทั้งหมด" ไม่ใช่ partial patch — เอาทีมงานออกจากกิจกรรมแล้ว resync ก็จะเอาออกจาก Songsue ด้วยเช่นกัน
- ตรวจสอบด้วย `npx tsc --noEmit`, `npm run lint` (ไม่มี error/warning ใหม่ในไฟล์ที่แก้), `npm run build` (ผ่าน), `npm test` (111/111 ผ่าน) — ยังไม่ได้ทดสอบ E2E จริงกับ local DB เพราะ Docker ไม่ได้เปิดอยู่ตอนแก้ (แนะนำให้ทดสอบ resync จริงอีกครั้งหลัง deploy ทั้งสองฝั่งแล้ว)
