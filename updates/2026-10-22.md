# ActiveCAMT v2.26.3 🎉

# อัปเดต ActiveCAMT ประจำวันที่ 22 ต.ค. 69

สรุปสำหรับวันที่ 22 ต.ค. 69 เอาไว้ลง Discord และให้ทีมที่เกี่ยวข้องอ่านกัน

---

## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- ไม่มีการเปลี่ยนแปลงที่เห็นได้จากหน้าจอ รอบนี้เป็นการปรับโครงสร้างโค้ดภายในเพื่อให้แก้ไขและดูแลระบบได้ง่ายขึ้น ทุกหน้าทำงานเหมือนเดิม

---

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- หน้าจัดการกิจกรรม, สแกนเนอร์, หน้าร้านค้า และหน้าข้อเสนอของชมรม/สาขา ทำงานเหมือนเดิมทุกประการ ข้อเสนอกิจกรรมของประธานชมรมและประธานสาขาใช้หน้าจอเดียวกันแล้ว

---

## ฝั่งทีม (technical changelog)

- **Refactor:** แยกหน้าใหญ่ (events, dashboard, scanner, shop, form builder) เป็น state hook กับ section components ไม่มีการเปลี่ยนพฤติกรรม
- **API:** route ทุกตัวไม่ import `@/db` แล้ว การ query ทั้งหมดย้ายไปอยู่ใน service ใต้ `src/modules/` โดย auth/role gate, scope check และการ audit log คงอยู่ที่เดิม (PDPA และสิทธิ์เข้าถึงไม่เปลี่ยน)
- **ไม่มีการเปลี่ยน DB schema หรือ migration**
- **ตรวจสอบแล้ว:** `npm run build`, `tsc`, `npm run lint` (ไม่มี error ใหม่) และ `vitest` 411 tests ผ่าน; ทดสอบหน้าหลักบนเบราว์เซอร์กับฐานข้อมูลทดสอบ

---

# ActiveCAMT v2.26.4 🎉

## ฝั่งทีม (technical changelog)

- **เอกสารภายใน:** ปรับเช็กลิสต์ `safe-deploy` ให้ตรงกับวิธีที่ทีมทำงานจริง คือ push ตรงเข้า `main` โดยไม่ใช้ feature branch หรือ PR และไม่ใส่ trailer ผู้ร่วมเขียนใน commit
- **Repo:** เอา `CLAUDE.md` ออกจาก `.gitignore` แล้วใช้ไฟล์ยกเว้นในเครื่อง (`.git/info/exclude`) แทน เพื่อไม่ให้ชื่อไฟล์โผล่ใน repo
- **ไม่มีการเปลี่ยนโค้ดของแอป, ไม่มีการเปลี่ยน DB schema หรือ migration** และไม่กระทบนักศึกษาหรือแอดมิน

---

รอบนี้ push ตรงเข้า `main` โดยไม่เปิด PR (commit `8e22ea6` และ `a58739d` ซึ่งแก้เลขเวอร์ชันใน `package.json`) ตัดแพ็กเกจเป็น **tag/release v2.26.4**
