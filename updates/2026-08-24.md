## ฝั่งนักศึกษา (สิ่งที่ user จะเห็น)

- **ขยาย QR โค้ดจ่ายเงินตอนสั่งซื้อของในร้านค้าให้ใหญ่ขึ้น** ตอนกดสั่งซื้อแล้วเจอหน้า "ช่องทางการชำระเงิน" QR พร้อมเพย์/บัญชีธนาคารที่แสดงไว้เดิมเล็กไปสแกนยาก ตอนนี้ขยายให้ใหญ่ขึ้นและปรับตามขนาดหน้าจอ สแกนจ่ายเงินได้ง่ายขึ้น

## ฝั่งแอดมิน/ทีมงาน (สิ่งที่ staff จะเห็น)

- **แก้บั๊กบันทึกตั้งค่า QR ร้านค้าไม่ได้** ที่หน้า "ตั้งค่าร้านค้า" (`/admin/shop`) ก่อนหน้านี้พออัปโหลดรูป QR พร้อมเพย์/บัญชีธนาคารแล้วกดบันทึก ระบบจะขึ้น error "qrImageUrl: Invalid URL" ทุกครั้ง ตอนนี้อัปโหลดแล้วกดบันทึกได้ตามปกติแล้ว

## ฝั่งทีม (technical changelog)

### แก้ validation ของ QR ร้านค้า (PR #221)

- **Bug fix:** `qrImageUrl` ในตาราง settings ของร้านค้าเดิม validate ด้วย `z.string().url()` ซึ่งบังคับให้เป็น absolute URL เต็มรูปแบบ แต่ endpoint `/api/upload` บนเซิร์ฟเวอร์ self-hosted ปัจจุบัน (ไม่มี Supabase storage env vars แล้ว) จะ fallback ไปเก็บไฟล์บน disk แล้วคืนค่าเป็น relative path อย่าง `/uploads/x.webp` แทน ทำให้ validation ล้มเหลวทุกครั้ง แก้โดยเปลี่ยนเป็น `z.string()` เฉย ๆ ให้ตรงกับ pattern ที่ `imageUrls` ของสินค้าร้านค้าใช้อยู่แล้วใน `shop-product-schema.ts`
- ตรวจสอบแล้วด้วย `npm run lint` และ `npm run build` ไม่พบ error ใหม่จากไฟล์ที่แก้ในรอบนี้

### ขยาย QR หน้า checkout ร้านค้า (PR #222)

- **Mobile/UI:** `src/app/dashboard/shop/ShopClient.tsx` เปลี่ยน QR รูปการชำระเงินจากขนาดตายตัว 200x200px เป็นขนาดตอบสนองตามความกว้างของ modal (`width: 100%`, `maxWidth: 320`) พร้อมคง aspect ratio 1:1 ไว้ ทำให้แสดงผลใหญ่ขึ้นทั้งบนมือถือและจอกว้าง
- ตรวจสอบแล้วด้วย `npm run lint` และ `npm run build` ไม่พบ error ใหม่จากไฟล์ที่แก้ในรอบนี้
